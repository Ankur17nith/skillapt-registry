# Security Policy

## Supported Versions

Only the latest active minor release receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in the Skillapt Registry, please **do not** open a public issue or discuss it publicly.

Instead, please report the vulnerability privately using one of the following methods:

1. **GitHub Security Advisory**: Submit a private report via the [Security Advisories](https://github.com/Ankur17nith/skillapt-registry/security/advisories/new) tab.
2. **Email**: Send details to `security@skillapt.dev` (or the maintainer contact).

Please include:
- Description of the vulnerability and attack scenario
- Step-by-step reproduction steps or proof-of-concept
- Affected endpoints, methods, or components
- Potential impact and any suggested mitigations

## Response SLA

- **Initial Acknowledgement**: Within 24 hours of report receipt.
- **Triage & Severity Assessment**: Within 48 hours.
- **Status Updates**: Every 72 hours until resolution.
- **Fix & Public Disclosure**: We aim to release a patched version within 7 business days for critical issues and 14 business days for high/medium severity issues. Coordinated disclosure will follow once a patch is deployed.
